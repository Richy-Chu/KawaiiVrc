KawaiiVrc Rust shell

reading your local data…

Sign in to VRChat

Your password is sent straight to VRChat and never written to disk.

Two-factor code

Enter the code from your authenticator app.

Chatbox

Sent over OSC to 127.0.0.1:9000. Turn on OSC in VRChat's Action Menu first. Lines are trimmed to 144 characters at a word boundary.

Shell settings

Stored in %LOCALAPPDATA%\KawaiiVrcShell\settings.json. The other app's settings are untouched.

Updates

Checks the signed release manifest and installs a newer build in place.

Shared history

The shell records what it sees into its own log. Import it into the shared activity history once the other app is closed, so both show one timeline.
